# Deploying to a single server (AWS EC2 + Docker Compose + Caddy)

The live site runs the stack defined in `docker-compose.prod.yml` on one EC2
instance: the Flask app (gunicorn), PostgreSQL 16 + pgvector, Redis 7, and
Caddy in front for automatic HTTPS. Only Caddy is published (ports 80/443);
Postgres, Redis and the app stay on the internal Docker network.

## 1. Prepare the server

- Launch an EC2 instance (any recent Linux with Docker support) and attach a
  security group that allows inbound **22** (SSH, from your IP only), **80**
  and **443**.
- Install Docker Engine and the Docker Compose plugin
  (see <https://docs.docker.com/engine/install/>).
- Point a DNS name at the instance's public IP — for example a free DuckDNS
  name, or use `<public-ip>.sslip.io` with no domain at all. Caddy needs this
  name to obtain a Let's Encrypt certificate.

## 2. Get the code and configure it

```bash
git clone https://github.com/olivia0401/parent-check.git
cd parent-check
cp .env.prod.example .env
```

Edit `.env` (it is gitignored — never commit it):

| Variable | Value |
|---|---|
| `POSTGRES_USER` / `POSTGRES_DB` | any names (defaults are fine) |
| `POSTGRES_PASSWORD` | a long random string |
| `APP_ENV` | `production` — the app then refuses to start without `SECRET_KEY` and marks cookies `Secure` |
| `SECRET_KEY` | `python3 -c "import secrets; print(secrets.token_urlsafe(48))"` |
| `GEMINI_API_KEY` | optional — enables the AI second opinion, RAG and screenshot OCR |
| `SITE_ADDRESS` | the DNS name from step 1, e.g. `yourname.duckdns.org` |

## 3. Start it

```bash
docker compose -f docker-compose.prod.yml up -d --build
docker compose -f docker-compose.prod.yml ps
docker compose -f docker-compose.prod.yml logs -f web
```

On first start the app creates the database schema (`db.init_db()`), and if
`GEMINI_API_KEY` is set it seeds the zh/en knowledge bases from `data/`. Caddy
fetches the HTTPS certificate on the first request to `https://$SITE_ADDRESS`.

`/metrics` is not served publicly (see `Caddyfile`); scrape `web:8000/metrics`
from inside the Docker network if you run Prometheus.

## 4. Update after a code change

```bash
cd parent-check
git pull
docker compose -f docker-compose.prod.yml up -d --build
```

Data lives in the `pgdata` volume and survives rebuilds. Caddy's certificates
live in `caddy_data`.

## Other targets

- **Render** — `render.yaml` defines a free web service. It needs a
  `DATABASE_URL` pointing at a PostgreSQL database with the pgvector extension
  (set it in the Render dashboard); `SECRET_KEY` is generated by Render.
- **AWS ECS (Terraform)** — see [`infra/README.md`](infra/README.md) for the
  on-demand managed-services stack.
